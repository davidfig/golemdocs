# Changelog

What changed in each version of Golem Docs, newest first. It is shown in the app under Help ▸ What’s New.

Changes still being worked on go under the `Unreleased` heading, `## <next version> - Unreleased`; when that version ships, replace `Unreleased` with the release date (`## 0.1.0 - 2026-10-01`) and start a new heading with the next version. Group entries under `### Added`, `### Changed` or `### Fixed`, one line per user-visible change.
