# Third-party notices

Golem Docs ships some material written by others. Each keeps its own license, and the full license text sits next to it.

## Fonts

`client/public/fonts/`: open fonts metric-compatible with common Word fonts. The folders are named after the font they stand in for, not the font inside. Each folder has the font's `LICENSE.txt`; sources and hashes are pinned in `scripts/fonts/sources.ts`.

| Folder | Font | License |
|---|---|---|
| `arial`, `times-new-roman`, `courier-new` | Liberation Sans, Serif, Mono | SIL Open Font License 1.1 |
| `calibri` | Carlito | SIL Open Font License 1.1 |
| `cambria` | Caladea | SIL Open Font License 1.1 |
| `georgia` | Gelasio | SIL Open Font License 1.1 |
| `segoe-ui` | Selawik | SIL Open Font License 1.1 |
| `comic-sans-ms` | Comic Relief | SIL Open Font License 1.1 |
| `jetbrains-mono` | JetBrains Mono | SIL Open Font License 1.1 |
| `libertinus-math` | Libertinus Math | SIL Open Font License 1.1 |
| `noto-sans-*` | Noto Sans CJK (Adobe Source Han) | SIL Open Font License 1.1 |

The `-extra` folders hold more glyphs from the same fonts. The glyph atlases are generated from these fonts by `scripts/fonts`.

## PDF font data

`pdf/src/fonts/data.ts` is generated by `pdf/scripts/generate-font-data.py` from Adobe's Core 14 font metrics (AFM) and the Adobe Glyph List. Both are © Adobe Systems Incorporated: the AFM files may be used, copied and distributed for any purpose, and the Adobe Glyph List is under the BSD 3-Clause License. This file is the one part of the `pdf` package that isn't MIT.

## npm dependencies

None of the npm dependencies end up in what ships to users except `libheif-js` and `polygon-clipping` in the client bundle. Their licenses are in their packages under `node_modules`.
