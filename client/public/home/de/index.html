In einer Minute startklar.

Es gibt nichts zu installieren und nichts, wofür Sie sich registrieren müssten.

  1. Ein Dokument öffnen

    Ziehen Sie eine Datei ins Fenster oder beginnen Sie ein neues, leeres Dokument.

  2. In jedem Format bearbeiten

    Tippen, formatieren, ein PDF kommentieren oder mit „Konvertieren in“ zu Markdown wechseln.

  3. Teilen oder herunterladen

    Laden Sie eine Datei für jemand anderen herunter, ganz ohne Konto. Oder schließen Sie ein Abo ab und senden Sie einen Link zum gemeinsamen Bearbeiten.

Kostenlos nutzbar. Mit Abo: Synchronisierung, Freigabe und KI.

Golem Docs funktioniert vollständig ohne Konto. Für die Synchronisierung Ihrer Dokumente zwischen Geräten, das Teilen und den KI-Assistenten brauchen Sie ein Abo: 5 $ im Monat. Jederzeit kündbar.

  • Kostenlos, ohne KontoBearbeiten, konvertieren und herunterladen, so viel Sie möchten. Dokumente werden in Ihrem Browser gespeichert und nie an uns gesendet.
  • Mit einem AboIhre Dokumente folgen Ihnen auf jedes Gerät. Teilen Sie einen Link oder laden Sie Personen ein, live gemeinsam zu bearbeiten. Nutzen Sie den KI-Assistenten, um Ihr Dokument zu lesen und zu bearbeiten. Melden Sie sich zum Abonnieren mit Google, Microsoft, GitHub oder Apple an.
  • Geteilte Dokumente zu öffnen ist kostenlosWenn ein Abonnent ein Dokument mit Ihnen teilt, müssen Sie sich nur anmelden, um es zu öffnen – und es zu bearbeiten, wenn er oder sie es erlaubt.
  • Wenn Sie kündigenIhre Dokumente bleiben in Ihrem Browser, und für das Herunterladen einer Datei brauchen Sie weder ein Konto noch ein Abo.
