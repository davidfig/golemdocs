Why I built this

I'm David. Obsidian runs my life, but PDFs kept getting in the way: I was always hunting for a tool to convert one or edit one. ZIP files made it more interesting, because an archive can hold anything, so an editor that opens one has to open whatever is inside. I thought it would be fun if it could open every kind of document there is, and I have been building toward that ever since.

Much of the code was written with Claude, with me steering (I promise I could have coded it myself, but it would have taken years). Golem Docs is still growing, so if a file won't open the way it should, tell me and it goes on the list.
