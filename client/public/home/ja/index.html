あらゆるものを、ひとつのエディターで。

Word ファイル、PDF、Markdown のメモ、CSV、SVG、そのほかたいていのドキュメントを放り込めば、そのまま編集を始められます。操作感は Word 2003 のようです。自分が欲しかったので作りました。

無料で試す 機能を見る

ブラウザーとデスクトップアプリで無料（モバイルアプリは近日公開）。アカウント不要、広告なし。同期と共有は月額 $3 で、25 GB のストレージ付きです。

おばあちゃんのラザニア

Word で書き起こし、メモには Markdown で残し、冷蔵庫に貼るために PDF で印刷しました。最初から最後まで同じレシピです

作った理由

David といいます。私の生活は Obsidian が支えていますが、PDF がいつも邪魔をしました。変換したり編集したりするツールを、そのたびに探し回っていたのです。ZIP ファイルのおかげで話がおもしろくなりました。アーカイブには何でも入るので、それを開けるエディターは中身が何であれ開けなければなりません。あらゆる種類のドキュメントを開けたら楽しいだろうと思い、それ以来ずっと、その目標に向かって作り続けています。

コードの多くは Claude と一緒に、私が舵を取りながら書きました (自分で書こうと思えば書けたと誓って言えますが、何年もかかったでしょう)。Golem Docs はまだ成長中です。対応していないファイル形式や足りない機能があれば、追加します。

何を放り込まれても開けるように作りました。

多くのエディターは 1 つの形式しか得意としません。私は、全部こなせるものが欲しかったのです。

『戦争と平和』でも速いです。

1,006 ページすべてを、ページ グリッドで表示しています。本全体から 1 つの段落まで拡大し、また戻します。エディターはすべてのページを、グラフィックスカードで自分で描画するので、大きなドキュメントでも軽快に動きます。

ほかにも、いくつか。

何も失わずに形式を変更 Word、Markdown、Web ページの間で切り替えられます。元に戻せば、書式も元どおりになります。 形式を変換する → すべての文書を検索 すべての文書から単語や #タグ を探せます。結果は該当する段落で開きます。ブラウザー自身のインデックスを使うので、オフラインでも動作します。

Obsidian から移行 Vault は Markdown ノートのフォルダーです。読み込めば、ノートがそれぞれのフォルダーに入ります。 Obsidian Vault の読み込み → 自分好みに ダークモード付きの配色を選び、ツールバーを並べ替え、11 の言語で使えます。 テーマと言語 →

1 分で始められます。

インストールも、登録も必要ありません。

  1. ドキュメントを開く

    ファイルをウィンドウにドロップするか、新しい白紙のドキュメントを始めます。

  2. どんな形式でも編集

    入力、書式設定、PDF への書き込み、「変換先」での Markdown への切り替えができます。

  3. 共有またはダウンロード

    アカウントなしで、ほかの人向けにファイルをダウンロードできます。または、サブスクリプションに登録してリンクを送り、一緒に編集できます。

無料で使えます。購読料は、サーバー代に充てています。

編集はお使いの端末の中で動くので、無料で提供しても私にはお金がかかりません。Golem Docs はアカウントなしで、ブラウザーでもデスクトップアプリでも、登場後はモバイルアプリでも完全に動作します。同期と共有にはサーバーとストレージが必要です。サブスクリプションは月額 $3 で、その費用をまかない、残りは Golem Docs の開発を続けるために使います。いつでも解約できます。

  • 無料、アカウント不要編集、変換、ダウンロードをブラウザー、デスクトップアプリ、そしてまもなくモバイルアプリで、好きなだけ。ドキュメントは端末に保存され、私に送られることはありません。
  • $3 の使い道同期は、ドキュメントを私のサーバーに置いて、どのデバイスにもついてくるようにします。アカウントの容量は版の履歴を含めて 25 GB で、いっぱいになると古い自動保存の版から順に削除されます。共有は、みんなでリアルタイムに編集できるようにします。登録するには、Google、Microsoft、GitHub、Apple でサインインします。
  • 共有されたドキュメントを開くのは無料購読者があなたとドキュメントを共有した場合、開くにはサインインするだけで、許可されていれば編集もできます。
  • 解約した場合ドキュメントはブラウザーに残ります。ファイル 1 つでも、すべてのファイルを ZIP にまとめても、ダウンロードにアカウントやサブスクリプションは必要ありません。

機能をリクエストする

無料ユーザーも購読者もリクエストできます。購読しても順番は早くなりません。サインインしている場合は、アプリの「ヘルプ › フィードバックを送信」からも送れます。

プラグインに意味があったのは、足りない機能が誰かの数週間の余暇を意味した時代です。AI がコードを書く手伝いをしてくれる今は、足りない機能はそのまま作れます。だから、アドオンを探してもらうのではなく、テストつきでアプリに組み込みます。

そのほうがシンプルです。文書のそばで動くサードパーティのコードはありません。新しい機能は、アプリのほかの部分と同じ見た目と動作で、11 言語すべてに対応しています。アプリが変わるときは機能も一緒に変わるので、壊れることはありません。

文書の中でやりたいのに Golem Docs でできないことや、開けないファイル形式があれば、教えてください。リクエストはすべて読んでいます。日付はお約束できませんが、よく求められるものは先に作られることが多いです。

デスクトップで Golem Docs を。

専用ウィンドウで同じエディタを使えます。保管フォルダにドキュメントが通常のファイルとして保存され、ほかのアプリでファイルを変更するとその変更がここに反映され、ここでの変更もファイルに反映されます。

Windows でアプリの発行元が不明と表示されることがあります。「詳細情報」を選び、「実行」を選んでください。
