설치할 것도, 가입할 것도 없습니다.

  1. 문서 열기

    파일을 창에 끌어다 놓거나 새 빈 문서를 시작하세요.

  2. 어떤 형식이든 편집

    입력하고, 서식을 지정하고, PDF에 표시하거나, 다음으로 변환으로 Markdown으로 전환하세요.

  3. 공유하거나 다운로드

    계정 없이 다른 사람을 위해 파일을 다운로드하세요. 또는 구독하고 링크를 보내 함께 편집하세요.

무료로 사용하세요. 동기화, 공유, AI는 구독으로.

Golem Docs는 계정 없이도 완전히 동작합니다. 기기 간 문서 동기화, 공유, AI 어시스턴트에는 구독이 필요합니다: 월 5달러. 언제든 해지할 수 있습니다.

  • 무료, 계정 불필요원하는 만큼 편집하고, 변환하고, 다운로드하세요. 문서는 브라우저에 저장되며 저희에게 전송되지 않습니다.
  • 구독하면문서가 어떤 기기에서든 따라옵니다. 링크를 공유하거나 사람들을 초대해 실시간으로 함께 편집하세요. AI 어시스턴트로 문서를 읽고 편집하세요. 구독하려면 Google, Microsoft, GitHub 또는 Apple로 로그인하세요.
  • 다른 사람이 공유한 문서를 여는 것은 무료구독자가 문서를 공유하면 로그인만 하면 열 수 있고, 허용해 준 경우 편집도 할 수 있습니다.
  • 해지하면문서는 브라우저에 그대로 남으며, 파일을 다운로드하는 데에는 계정도 구독도 필요하지 않습니다.

문서는 당신의 것입니다.

개인정보 처리방침은 읽히도록 썼습니다. 짧고, 무엇을 수집하고 왜 수집하는지 설명합니다.

  • 광고 없음, 데이터 판매 없음데이터를 판매하지 않으며 광고도 보여 주지 않습니다.
  • 추적 없음분석 도구도, 광고 추적기도 없습니다.
  • 내 파일, 전부 가져가세요모든 문서는 당신에게 속한 진짜 파일입니다. 파일 ▸ 모두 다운로드 (ZIP)를 선택하면 보관 중인 모든 것을 언제든지, 계정 없이 하나의 ZIP으로 저장합니다.
