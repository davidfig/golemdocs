Начните работу за минуту.

Ничего не нужно устанавливать и нигде не нужно регистрироваться.

  1. Откройте документ

    Перетащите файл в окно или создайте новый пустой документ.

  2. Редактируйте в любом формате

    Печатайте, форматируйте, размечайте PDF или переключитесь на Markdown через «Преобразовать в».

  3. Поделитесь или скачайте

    Скачайте файл для другого человека — аккаунт не нужен. Или оформите подписку и отправьте ссылку для совместного редактирования.

Бесплатно. Подписка — для синхронизации, общего доступа и ИИ.

Golem Docs полностью работает без аккаунта. Синхронизация документов между устройствами, общий доступ и ИИ-ассистент требуют подписки: 5 $ в месяц. Отменить можно в любой момент.

  • Бесплатно, без аккаунтаРедактируйте, конвертируйте и скачивайте сколько угодно. Документы сохраняются в вашем браузере и никогда не отправляются нам.
  • С подпискойВаши документы следуют за вами на любое устройство. Делитесь ссылкой или приглашайте людей редактировать вместе в реальном времени. Используйте ИИ-ассистента, чтобы читать и редактировать документ. Для подписки войдите через Google, Microsoft, GitHub или Apple.
  • Открывать чужие документы бесплатноЕсли подписчик делится с вами документом, достаточно войти, чтобы открыть его, а также редактировать, если он вам это разрешит.
  • Если вы отмените подпискуВаши документы останутся в браузере, а для скачивания файла никогда не нужны ни аккаунт, ни подписка.
