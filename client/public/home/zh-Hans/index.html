我为什么做这个

我是 David。Obsidian 管着我的生活，可 PDF 总来添乱：我老得到处找工具来转换或编辑它。ZIP 文件让事情更有意思，因为压缩包里什么都可能有，所以能打开它的编辑器，就得能打开里面的一切。我想，要是它能打开世上所有类型的文档，那该多好玩，从那以后我就一直朝这个方向做。

大部分代码是和 Claude 一起写的，由我掌舵（我保证自己也能写，只是得花上好几年）。Golem Docs 还在成长：如果有不支持的文件类型，或缺少某个功能，我会把它加上。

不管我丢过去什么，都能打开。

多数编辑器只擅长一种格式。我想要一个全都能处理的。

无需安装，也无需注册。

    把文件拖到窗口上，或新建一份空白文档。

  2. 任何格式都能编辑

  3. 共享或下载

缺了什么？告诉我，它就会进入应用。

Golem Docs 没有插件商店，以后也不会有。功能和改进，我会一直自己做进应用里。

提交功能请求

免费用户和订阅用户都可以提。订阅不能插队。登录后，也可以在应用里使用“帮助 › 发送反馈”。

插件曾经很有意义，因为缺一个功能就意味着某人好几周的业余时间。如今有 AI 帮我写代码，缺的功能直接做出来就行，所以我把它连同测试一起做进应用，而不是让你去找附加组件。

这样一切都更简单。你的文档旁边不会运行任何第三方代码。新功能的外观和用法与应用的其他部分一致，支持全部 11 种语言。应用更新时，功能随之更新，所以不会失灵。

如果有你在文档里想做、Golem Docs 却做不到的事，或者它打不开的文件类型，请告诉我。每一条请求我都会读。我无法承诺日期，但大家常提的需求往往会先做。
