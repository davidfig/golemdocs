我為什麼做這個

我是 David。我的生活靠 Obsidian 運轉，但 PDF 老是礙事：我總是在找工具來轉換或編輯它。ZIP 檔讓事情更有意思，因為壓縮檔裡什麼都可能有，所以能開啟壓縮檔的編輯器，就得能開啟裡面的任何東西。我覺得如果它能開啟所有種類的文件，應該會很好玩，從那時起我就一直朝這個方向做。

大部分程式碼是和 Claude 一起寫的，由我掌舵（我保證我自己也寫得出來，只是得花上好幾年）。Golem Docs 還在成長：如果有不支援的檔案類型，或缺少某個功能，我會把它加上。

我丟什麼給它，它都能開。

一分鐘即可上手。

不需安裝，也不需註冊。

  1. 開啟文件

    把檔案拖曳到視窗上，或建立一份空白文件。

  2. 任何格式都能編輯

    輸入、設定格式、標註 PDF，或用「轉換為」切換到 Markdown。

  3. 共用或下載

    不需帳號，即可為他人下載檔案。或者訂閱後傳送連結，一起編輯。

Golem Docs 沒有外掛商店，以後也不會有。功能與改進，我會一直自己做進應用程式裡。

提交功能請求

免費使用者和訂閱者都可以提。訂閱不能插隊。登入後，也可以在應用程式裡使用「說明 › 傳送意見反應」。

外掛曾經很有意義，因為缺一個功能就意味著某人好幾週的業餘時間。如今有 AI 幫我寫程式，缺的功能直接做出來就行，所以我把它連同測試一起做進應用程式，而不是讓你去找附加元件。

這樣一切都更簡單。你的文件旁邊不會執行任何第三方程式碼。新功能的外觀和用法與應用程式的其他部分一致，支援全部 11 種語言，AI 助理也能使用。應用程式更新時，功能隨之更新，所以不會壞掉。

如果有你在文件裡想做、Golem Docs 卻做不到的事，或是它打不開的檔案類型，請告訴我。每一則請求我都會讀。我無法承諾日期，但大家常提的需求往往會先做。

桌面版 Golem Docs。

同一個編輯器，擁有獨立的視窗，並透過保管庫資料夾把你的文件以一般檔案存放在電腦上。在其他應用程式中變更檔案，變更會顯示在這裡，反之亦然。

Windows 可能會提示應用程式來自未知的發行者。請選擇「其他資訊」，然後選擇「仍要執行」。
