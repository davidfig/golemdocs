# Convert documents between formats

Golem Docs opens the documents, web pages, notes, data, and pictures you already have. Switch a document from one shape to another with File ▸ Convert To, and keep working. Nothing is uploaded to do it: conversion happens in your browser.

## Change shape, then change back

Convert To changes what a document is edited as. Turn a Word document into Markdown to work on it as plain text with `#` headings, then convert it back, and your formatting comes back with it. Golem Docs keeps what the new format can't hold, so a round trip returns what you started with.

Some conversions can't keep everything. Going from a richer format to a poorer one (Word to plain text, for example) drops formatting the target can't express. Going the other way (text to Markdown to Word) loses nothing.

## What you can open and save

- **Word processors:** Word (.docx, and .docm and .dotx), OpenDocument Text, and Rich Text. Older Word 97–2003 (.doc) files open too, and save as .docx.
- **Web and books:** HTML, EPUB, Web Archive (MHTML), and email messages (.eml).
- **Markup:** Markdown, LaTeX, AsciiDoc, reStructuredText, Org, MediaWiki, and Textile.
- **Notebooks:** Jupyter notebooks (.ipynb).
- **Data:** CSV and TSV open as tables you can edit, and save as the same file.
- **PDF:** open it to mark it up or [edit it](/home/pdf), or convert it to another format as a reflowed copy.
- **Pictures:** PNG, JPEG, and WebP, plus GIF, BMP, and SVG, which open as pictures and save as PNG. See [editing pictures](/home/images).
- **Plain text:** .txt and the many text-based files that look like it. Very large ones open in the [large file viewer](/home/large-files).

## Turn a document into a picture

Convert a document to PNG, JPEG, or WebP and you get a picture made from its pages. The original document stays as it was. PNG keeps every pixel. JPEG and WebP compress, so they are smaller and slightly lossy.

## A few conversions worth knowing

- **A CSV or TSV** is a table in Golem Docs. Edit cells, add rows and columns, and download the same CSV.
- **A Markdown note** can become a Word document, a web page, or a PDF, with headings, lists, tables, links, and math carried across.
- **An email (.eml)** opens as a readable document you can edit and save.
- **A Jupyter notebook** opens as a document you can read and edit.
- **A PDF** converted to Word is a reflowed copy: the text is yours to edit, but the page layout won't match the original. To change a PDF and keep it a PDF, use [Edit PDF](/home/pdf).

## Private by default

Signed out, files never leave your browser, whether you open, convert, or download them. You don't need an account to convert anything.
