# Convert Markdown to Word, and back

Golem Docs opens a Markdown note and turns it into a Word document, a web page, or a PDF with File ▸ Convert To. Headings, lists, tables, links, and math come across, and nothing is uploaded: the conversion happens in your browser.

## Markdown to Word

1. **Open the note.** Drop the .md file onto the window, or choose File ▸ Open.
2. **Choose File ▸ Convert To ▸ Word.** The note becomes a Word document with real headings, lists, and tables.
3. **Download it** with File ▸ Download to get a .docx.

## Word to Markdown

Open a .docx and choose File ▸ Convert To ▸ Markdown to work on it as plain text with `#` headings. Convert it back and its formatting comes back with it, because Golem Docs keeps what Markdown can't hold. Going from a richer format to a poorer one can drop formatting the target can't express, so keep the original if the formatting matters.

## For people who live in Obsidian

Golem Docs reads `[[wiki links]]` and `![[embeds]]`, shows front matter properties, and writes them back as Markdown that Obsidian reads again. To bring a whole vault in, see [importing an Obsidian vault](/home/obsidian).

## Other formats

The same menu converts between Word, OpenDocument, Rich Text, HTML, EPUB, LaTeX, Typst, AsciiDoc, reStructuredText, and more. The full list is on the [convert page](/home/convert).
