# Welcome to Golem Docs

Golem Docs is a document editor that lives in your browser. It opens Word documents, PDFs, Markdown, web pages, OpenDocument and plain text, and lets you keep working on them in whichever of those shapes you need.

This page is a document like any other. Click anywhere and start typing to try it out.

## What it does

- **Open almost anything.** Drop a file onto the window, or choose Open from the File menu. Word (.docx), OpenDocument (.odt), PDF, Markdown, HTML and plain text all open as documents you can edit.
- **Change shape without losing anything.** Convert To, in the File menu, switches what a document is edited as. It stays the same document underneath, so going from Word to Markdown and back gives you your fonts and colors again. Only a download is trimmed to what its format can hold.
- **Mark up PDFs.** A PDF keeps its own pages, and you can highlight, underline, strike out and leave notes on them.
- **Comment.** Select some text and choose Comment from the Insert menu. Comments show down the right of the page.
- **Work together.** Collaborate, in the File menu, opens the document for editing together, with each person's changes showing up live.

## Saving

There is no Save button. Every change is kept in this browser a moment after you make it, and you don't need an account. The Dashboard, in the File menu, shows all your documents. If you sign in, Save to Cloud keeps a copy in your account so you can open it anywhere.

## Getting started

1. Choose New from the File menu for a blank document, or open one of your own.
2. Write, format and comment as you would in any word processor.
3. When you need a file for someone else, choose Download from the File menu.

## About the name

In Jewish tradition, a golem is a figure shaped from clay and brought to life by a word. In the best-known telling, Rabbi Judah Loew of Prague shapes one from the mud of the Vltava river and writes *emet*, the Hebrew word for "truth," on its forehead. Erase the first letter and the word becomes *met*, "dead," and the golem returns to clay.

A document is much the same: a shapeless thing that words bring to life. Golem Docs lets yours take whatever form you need, Word or Markdown or PDF or a web page, while what you wrote stays true underneath.
