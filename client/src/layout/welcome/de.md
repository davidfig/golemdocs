# Willkommen bei Golem Docs

Ein Dokumenteditor, der in Ihrem Browser läuft und jede Art von Dokument öffnen soll: Word, PDF, Markdown, Webseiten, sogar eine CSV-Datei, und weitere folgen. Sie können in der Form weiterarbeiten, die Sie gerade brauchen. Diese Seite ist ein Dokument wie jedes andere: Klicken Sie irgendwo hinein und tippen Sie los.

## Was es kann

- **Fast alles öffnen.** Ziehen Sie eine Datei auf das Fenster oder wählen Sie im Menü Datei den Befehl Öffnen.
- **Die Form wechseln, ohne etwas zu verlieren.** Mit Konvertieren in, im Menü Datei, ändern Sie, als was ein Dokument bearbeitet wird. Beim Zurückwechseln ist Ihre Formatierung wieder da.
- **PDFs kommentieren.** Markieren, unterstreichen, durchstreichen und Notizen hinterlassen, direkt auf den Seiten eines PDFs.
- **Zusammenarbeiten.** Freigeben, im Menü Datei, gibt Ihnen einen Link. Alle, die ihn öffnen, bearbeiten dasselbe Dokument, und Änderungen erscheinen live. Sie können auch für bestimmte Personen freigeben.

## Ausprobieren

1. **Die Form wechseln.** Wählen Sie im Menü Datei Konvertieren in, dann Markdown. Diese Seite wird zu reinem Text mit `#`-Überschriften, und Sie können sie zurückkonvertieren.
2. **Daten öffnen.** Ziehen Sie eine CSV-Datei auf das Fenster. Sie öffnet sich als Tabelle, die Sie bearbeiten können, und wird als dieselbe CSV heruntergeladen.
3. **Gemeinsam bearbeiten.** Wählen Sie im Menü Datei Freigeben, dann Link abrufen, und öffnen Sie den Link in einem zweiten Fenster. Tippen Sie in einem und sehen Sie zu, wie sich das andere aktualisiert.

Wenn Sie so weit sind, wählen Sie im Menü Datei Neu für ein leeres Dokument, oder Herunterladen, wenn Sie eine Datei für jemand anderen brauchen.

## Und mehr

- **Word, OpenDocument, Rich Text, PDF, HTML, EPUB, Markdown, LaTeX, AsciiDoc, reStructuredText, Org, CSV und reiner Text** lassen sich alle als bearbeitbare Dokumente öffnen.
- **Links und Tabellen:** Strg+K (Cmd+K auf dem Mac) versieht die Markierung mit einem Link, und die Schaltfläche Tabelle in der Symbolleiste fügt ein Raster ein.
- **Rechtschreibung und Grammatik:** F7 drücken. Suchen und Ersetzen finden Sie im Menü Bearbeiten.
- **Kommentare:** Text markieren und im Menü Einfügen den Befehl Kommentar wählen.
- **Farbschemata, Dunkelmodus und Symbolleisten** finden Sie im Menü Ansicht, und im Menü Extras ändern Sie die Sprache.

## Speichern

Es gibt keine Schaltfläche zum Speichern. Jede Änderung wird kurz nach dem Vornehmen in diesem Browser gesichert, und Sie brauchen kein Konto. Das Dashboard im Menü Datei zeigt alle Ihre Dokumente. Wenn Sie sich anmelden, werden sie stattdessen in Ihrem Konto gespeichert, sodass Sie sie auf jedem Gerät öffnen können.

## Zum Namen

In der jüdischen Überlieferung ist ein Golem eine Gestalt, die aus Lehm geformt und durch ein Wort zum Leben erweckt wird. In der bekanntesten Erzählung formt Rabbi Löw von Prag einen aus dem Schlamm der Moldau und schreibt *emet*, das hebräische Wort für „Wahrheit“, auf seine Stirn. Löscht man den ersten Buchstaben, wird daraus *met*, „tot“, und der Golem wird wieder zu Lehm.

Ein Dokument ist ganz ähnlich: etwas Gestaltloses, das Worte zum Leben erwecken. Golem Docs lässt Ihres jede Form annehmen, die Sie brauchen, Word oder Markdown oder PDF oder eine Webseite, während das, was Sie geschrieben haben, darunter wahr bleibt.
