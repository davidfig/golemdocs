# Welcome to Golem Docs

A document editor that lives in your browser, built to open every kind of document: Word, PDF, Markdown, web pages, even a CSV file, and more to come. It lets you keep working in whichever shape you need. This page is a document like any other: click anywhere and start typing.

## What it does

- **Open almost anything.** Drop a file onto the window, or choose Open from the File menu.
- **Change shape without losing anything.** Convert To, in the File menu, switches what a document is edited as, and going back gives you your formatting again.
- **Mark up PDFs.** Highlight, underline, strike out and leave notes on a PDF's own pages.
- **Edit PDFs.** Switch to Edit PDF to change a page's text where it sits, move, add or delete pictures and shapes, black out private details, and rearrange pages. Fill In types into a form's fields.
- **Work together.** Share, in the File menu, gives you a link. Everyone who opens it edits the same document, and changes show up live. You can also share with specific people.

## Try this

1. **Change shape.** In the File menu, choose Convert To, then Markdown. This page turns into plain text with `#` headings, and you can convert it back.
2. **Open some data.** Drop a CSV file onto the window. It opens as a table you can edit, and downloads as the same CSV.
3. **Edit together.** In the File menu, choose Share, then Get Link, and open the link in a second window. Type in one and watch the other update.

When you're ready, choose New from the File menu for a blank document, or Download when you need a file for someone else.

## And more

- **Word, OpenDocument, Rich Text, PDF, HTML, EPUB, Markdown, LaTeX, AsciiDoc, reStructuredText, Org, CSV and plain text** all open as documents you can edit.
- **Links and tables:** Ctrl+K (Cmd+K on a Mac) links the selection, and the toolbar's Table button inserts a grid.
- **Spelling and grammar:** press F7. Find and replace is in the Edit menu.
- **Comments:** select text and choose Comment from the Insert menu.
- **Themes, Dark Mode and toolbars** are in the View menu, and the Tools menu changes the language.

## Saving

There is no Save button. Every change is kept in this browser a moment after you make it, and you don't need an account. File ▸ Open shows all your documents. Sign in and they are saved to your account instead, so you can open them on any device.

## About the name

In Jewish tradition, a golem is a figure shaped from clay and brought to life by a word. In the best-known telling, Rabbi Judah Loew of Prague shapes one from the mud of the Vltava river and writes *emet*, the Hebrew word for "truth," on its forehead. Erase the first letter and the word becomes *met*, "dead," and the golem returns to clay.

A document is much the same: a shapeless thing that words bring to life. Golem Docs lets yours take whatever form you need, Word or Markdown or PDF or a web page, while what you wrote stays true underneath.
