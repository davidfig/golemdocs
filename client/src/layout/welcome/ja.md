# Golem Docs へようこそ

ブラウザーの中で動くドキュメント エディターで、あらゆる種類のドキュメントを開けるように作られています。Word、PDF、Markdown、Web ページ、さらには CSV ファイルなど、さまざまな形式に対応しています。必要な形のまま作業を続けられます。このページも他のドキュメントと同じです。どこでもクリックして、入力を始めてください。

## できること

- **ほとんど何でも開けます。** ファイルをウィンドウにドロップするか、「ファイル」メニューの「開く」を選びます。
- **内容を失わずに形式を変えられます。** 「ファイル」メニューの「変換先」でドキュメントの編集形式を切り替えられ、元に戻すと書式もそのまま戻ります。
- **PDF に書き込めます。** PDF のページ上で、蛍光ペン、下線、取り消し線、メモを追加できます。
- **PDF を編集できます。** 「PDF を編集」に切り替えると、ページ上のテキストをその場で書き換えたり、画像や図形を移動・追加・削除したり、機密情報を黒塗りしたり、ページを並べ替えたりできます。「入力」ではフォームのフィールドに入力します。
- **共同で編集できます。** 「ファイル」メニューの「共有」でリンクを取得できます。リンクを開いた人は全員が同じドキュメントを編集し、変更はリアルタイムで表示されます。特定の人と共有することもできます。共有は購読に含まれます。ひとりで編集する分には無料です。
- **AI に相談できます。** 隅にある AI アシスタントは、ドキュメントを読み、段落の書き換えや追加、テキストの書式設定、コメントの追加、フォームへの入力、別の形式への変換を行えます。「元に戻す」でその変更を取り消せます。購読に含まれます。「表示」›「AI アシスタント」で表示/非表示を切り替えます。

## 試してみましょう

1. **形式を変える。** 「ファイル」メニューの「変換先」から Markdown を選びます。このページが `#` の見出しが付いたテキストになり、元に戻すこともできます。
2. **データを開く。** CSV ファイルをウィンドウにドロップします。編集できる表として開き、ダウンロードすると同じ CSV になります。
3. **AI に相談する。** AI アシスタントを開き、このページの要約や見出しの強調を頼んでみてください。変更を取り消したいときは「元に戻す」を押します。これには購読が必要です。
4. **一緒に編集する。** 「ファイル」メニューの「共有」から「リンクを取得」を選び、そのリンクを 2 つ目のウィンドウで開きます。片方で入力すると、もう片方が更新されます。これにも購読が必要です。

準備ができたら、「ファイル」メニューの「新規作成」で白紙のドキュメントを作成するか、他の人にファイルを渡すときは「ダウンロード」を選びます。

## その他の機能

- **Word、OpenDocument、リッチ テキスト、PDF、HTML、EPUB、Markdown、LaTeX、AsciiDoc、reStructuredText、Org、CSV、テキスト** は、すべて編集可能なドキュメントとして開きます。
- **コマンドパレット:** Ctrl+Shift+P (Mac では Cmd+Shift+P) を押すと、あらゆるコマンドを検索して実行できます。
- **ページのサムネイル:** 「表示」›「ページ サイドバー」(Alt+P) で、ページを一覧から選んで移動できます。PDF では、ドラッグしてページを並べ替えたり、削除したりできます。
- **名前の変更:** メニュー バーの中央にあるドキュメント名をクリックすると、新しい名前を入力できます。
- **リンクと表:** Ctrl+K (Mac では Cmd+K) で選択範囲にリンクを設定でき、ツール バーの「表」ボタンで表を挿入できます。
- **スペルチェックと文章校正:** F7 キーを押します。検索と置換は「編集」メニューにあります。
- **コメント:** テキストを選択して、「挿入」メニューの「コメント」を選びます。他の人が返信でき、対応が済んだらコメントを解決済みにできます。
- **テーマ、ダーク モード、ツール バー** は「表示」メニューにあり、「ツール」メニューで言語を変更できます。

## 保存と購読

「保存」ボタンはありません。変更はしばらくするとこのブラウザーに自動的に保存され、アカウントも必要ありません。「ファイル」›「開く」で、すべてのドキュメントを確認できます。「ダウンロード」を選べば、いつでもファイルとして保存できます。ブラウザーへの保存とダウンロードは無料で、購読は必要ありません。

購読すると、同期、共有、内蔵の AI アシスタントが使えるようになります。

- **同期** でドキュメントがアカウントに保存され、どのデバイスからでも開けます。
- **共有と共同編集** をリンクまたは特定の人と行えます。
- **AI** は内蔵されており、設定は不要です。

購読は Golem Docs の開発を支援することにもなります。購読が終了しても、ドキュメントはこのブラウザーに残り、購読者から共有されたドキュメントは引き続き開けます。料金は[料金プラン](https://golemdocs.com/home/#pricing)をご覧になるか、「ファイル」›「購読する…」から始めてください。

## 名前について

ユダヤの伝承で、ゴーレムとは、粘土から作られ、言葉によって命を吹き込まれた存在です。最もよく知られた話では、プラハのラビ・レーヴがヴルタヴァ川の泥からゴーレムを作り、その額にヘブライ語で「真理」を意味する *emet* と書きました。最初の文字を消すと、この語は「死」を意味する *met* になり、ゴーレムは粘土に戻ります。

ドキュメントもこれとよく似ています。言葉によって命を吹き込まれる、形のないものです。Golem Docs では、Word でも Markdown でも PDF でも Web ページでも、必要な形をとらせることができ、その下では、あなたが書いた内容が真実のまま保たれます。
