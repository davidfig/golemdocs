# Golem Docs へようこそ

ブラウザーの中で動くドキュメント エディターで、あらゆる種類のドキュメントを開くことを目指しています。Word、PDF、Markdown、Web ページ、さらには CSV ファイルまで開くことができ、今後も対応を広げていきます。必要な形のまま作業を続けられます。このページも他のドキュメントと同じです。どこでもクリックして、入力を始めてください。

## できること

- **ほとんど何でも開けます。** ファイルをウィンドウにドロップするか、「ファイル」メニューの「開く」を選びます。
- **内容を失わずに形式を変えられます。** 「ファイル」メニューの「変換先」でドキュメントの編集形式を切り替えられ、元に戻すと書式もそのまま戻ります。
- **PDF に書き込めます。** PDF のページ上で、蛍光ペン、下線、取り消し線、メモを追加できます。
- **共同で編集できます。** 「ファイル」メニューの「共有」でリンクを取得できます。リンクを開いた人は全員が同じドキュメントを編集し、変更はリアルタイムで表示されます。特定の人と共有することもできます。

## 試してみましょう

1. **形式を変える。** 「ファイル」メニューの「変換先」から Markdown を選びます。このページが `#` の見出しが付いたテキストになり、元に戻すこともできます。
2. **データを開く。** CSV ファイルをウィンドウにドロップします。編集できる表として開き、ダウンロードすると同じ CSV になります。
3. **一緒に編集する。** 「ファイル」メニューの「共有」から「リンクを取得」を選び、そのリンクを 2 つ目のウィンドウで開きます。片方で入力すると、もう片方が更新されます。

準備ができたら、「ファイル」メニューの「新規作成」で白紙のドキュメントを作成するか、他の人にファイルを渡すときは「ダウンロード」を選びます。

## その他の機能

- **Word、OpenDocument、リッチ テキスト、PDF、HTML、EPUB、Markdown、LaTeX、AsciiDoc、reStructuredText、Org、CSV、テキスト** は、すべて編集可能なドキュメントとして開きます。
- **リンクと表:** Ctrl+K (Mac では Cmd+K) で選択範囲にリンクを設定でき、ツール バーの「表」ボタンで表を挿入できます。
- **スペルチェックと文章校正:** F7 キーを押します。検索と置換は「編集」メニューにあります。
- **コメント:** テキストを選択して、「挿入」メニューの「コメント」を選びます。
- **テーマ、ダーク モード、ツール バー** は「表示」メニューにあり、「ツール」メニューで言語を変更できます。

## 保存について

「保存」ボタンはありません。変更はしばらくするとこのブラウザーに自動的に保存され、アカウントも必要ありません。「ファイル」メニューの「開く」で、すべてのドキュメントを確認できます。サインインすると、ドキュメントは代わりにアカウントに保存されるため、どのデバイスからでも開けます。

## 名前について

ユダヤの伝承で、ゴーレムとは、粘土から作られ、言葉によって命を吹き込まれた存在です。最もよく知られた話では、プラハのラビ・レーヴがヴルタヴァ川の泥からゴーレムを作り、その額にヘブライ語で「真理」を意味する *emet* と書きました。最初の文字を消すと、この語は「死」を意味する *met* になり、ゴーレムは粘土に戻ります。

ドキュメントもこれとよく似ています。言葉によって命を吹き込まれる、形のないものです。Golem Docs では、Word でも Markdown でも PDF でも Web ページでも、必要な形をとらせることができ、その下では、あなたが書いた内容が真実のまま保たれます。
