# 欢迎使用 Golem Docs

一款在浏览器中运行的文档编辑器，目标是打开各种类型的文档：Word、PDF、Markdown、网页，甚至 CSV 文件，等等。它让你以最合适的形式继续编辑。本页和其他文档没有两样：在任何位置单击并开始输入即可。

## 功能

- **几乎什么都能打开。** 将文件拖动到窗口上，或从“文件”菜单中选择“打开”。
- **转换形式，内容不丢失。** “文件”菜单中的“转换为”可切换文档的编辑形式，转换回来时格式依然完好。
- **批注 PDF。** 在 PDF 的页面上突出显示、加下划线、加删除线并留下批注。
- **编辑 PDF。** 切换到“编辑 PDF”，即可原位修改页面上的文本、移动、添加或删除图片与图形、将机密内容涂黑，并重新排列页面。“填写”则可在表单域中输入。
- **协作。** “文件”菜单中的“共享”会给你一个链接。打开链接的人都会编辑同一份文档，更改即时显示。你也可以与特定人员共享。共享包含在订阅中；自己编辑是免费的。
- **询问 AI。** 角落里的 AI 助手可以阅读你的文档、改写或添加段落、设置文本格式、留下批注、填写表单并转换为其他格式，“撤销”可以收回它所做的更改。它包含在订阅中。“视图”›“AI 助手”可显示或隐藏它。

## 试试看

1. **转换形式。** 从“文件”菜单选择“转换为”，再选择 Markdown。本页会变成带有 `#` 标题的纯文本，你也可以再转换回来。
2. **打开数据。** 将 CSV 文件拖动到窗口上。它会以可编辑的表格打开，下载时仍是同一份 CSV。
3. **询问 AI。** 打开 AI 助手，让它总结本页或让某个标题更醒目，如果想收回更改，请按“撤销”。这一项需要订阅。
4. **协作。** 从“文件”菜单选择“共享”，再选择“获取链接”，并在第二个窗口中打开该链接。在其中一个窗口输入，看另一个窗口随之更新。这一项同样需要订阅。

准备好之后，从“文件”菜单选择“新建”创建空白文档，需要提供文件给他人时则选择“下载”。

## 还有更多

- **Word、OpenDocument、Rich Text、PDF、HTML、EPUB、Markdown、LaTeX、AsciiDoc、reStructuredText、Org、CSV 和纯文本**都能以可编辑的文档打开。
- **命令面板：** 按 Ctrl+Shift+P（Mac 为 Cmd+Shift+P）搜索并运行任何命令。
- **页面缩略图：** “视图”›“页面侧栏”（Alt+P）会显示一列页面，方便在页面之间跳转。在 PDF 中，可以拖动它们来重新排序，也可以删除。
- **重命名：** 单击菜单栏中间的文档名称即可输入新名称。
- **链接与表格：** 按 Ctrl+K（Mac 为 Cmd+K）为选择的文本加上链接，工具栏的“表格”按钮可插入表格。
- **拼写和语法：** 按 F7。“查找和替换”在“编辑”菜单中。
- **批注：** 选择文本，然后从“插入”菜单选择“批注”。其他人可以回复，处理完毕后你可以将批注标记为“解决”。
- **主题、深色模式和工具栏**在“视图”菜单中，“工具”菜单可切换语言。

## 保存与订阅

没有保存按钮。你所做的每项更改，随后都会保存在此浏览器中，也不需要账户。“文件”›“打开”会显示你所有的文档，需要文件时可随时选择“下载”。在浏览器中保存和下载都是免费的，无需订阅。

订阅会增加同步、共享和内置的 AI 助手：

- **同步** 会将你的文档保存到账户中，方便在任何设备上打开。
- **共享与协作** 可通过链接或与特定人员进行。
- **AI** 已内置，无需任何设置。

订阅也是支持 Golem Docs 开发的方式。如果订阅结束，你的文档仍保留在此浏览器中，你也仍然可以打开订阅者与你共享的文档。费用请查看[价格](https://golemdocs.com/home/#pricing)，或选择“文件”›“订阅…”开始使用。

## 关于名称

在犹太传统中，魔像（golem）是以黏土塑成、由一个字赋予生命的形体。最著名的传说中，布拉格的犹大·勒夫拉比用伏尔塔瓦河的泥土塑出一个魔像，并在它的额头写上 *emet*，希伯来文的“真理”。擦掉第一个字母，这个字就变成 *met*，意思是“死”，魔像便回归尘土。

文档也很相似：原本是无形之物，由文本赋予生命。Golem Docs 让你的文档能变成任何需要的形式，无论是 Word、Markdown、PDF 或网页，而你所写的内容在底层始终真实不变。
