# 歡迎使用 Golem Docs

一款在瀏覽器中運作的文件編輯器，目標是開啟所有類型的文件：Word、PDF、Markdown、網頁，甚至 CSV 檔案等等。它讓您以最合適的形式繼續編輯。這一頁和其他文件沒有兩樣：在任何位置點一下並開始輸入即可。

## 功能

- **幾乎什麼都能開啟。** 將檔案拖曳到視窗上，或從「檔案」功能表選擇「開啟」。
- **轉換形式，內容不流失。** 「檔案」功能表中的「轉換為」可切換文件的編輯形式，轉換回來時格式依然完整。
- **標註 PDF。** 在 PDF 的頁面上醒目提示、加底線、加刪除線並留下註解。
- **編輯 PDF。** 切換到「編輯 PDF」，即可就地修改頁面上的文字、移動、新增或刪除圖片與圖形、將機密內容塗黑，並重新排列頁面。「填寫」則是在表單欄位中輸入。
- **共同作業。** 「檔案」功能表中的「共用」會給您一個連結。開啟連結的人都會編輯同一份文件，變更即時顯示。您也可以與特定人員共用。共用包含在訂閱中；自己編輯是免費的。
- **詢問 AI。** 角落的 AI 助理可以閱讀您的文件、改寫或新增段落、設定文字格式、留下註解、填寫表單，並轉換為其他格式，而「復原」可以取消它所做的變更。它包含在訂閱中。「檢視」›「AI 助理」可顯示或隱藏它。

## 試試看

1. **轉換形式。** 從「檔案」功能表選擇「轉換為」，再選擇 Markdown。這一頁會變成帶有 `#` 標題的純文字，您也可以再轉換回來。
2. **開啟資料。** 將 CSV 檔案拖曳到視窗上。它會以可編輯的表格開啟，下載時仍是同一份 CSV。
3. **詢問 AI。** 開啟 AI 助理，請它摘要這一頁，或讓某個標題更醒目，若想取消變更，再按「復原」。這需要訂閱。
4. **一起編輯。** 從「檔案」功能表選擇「共用」，再選擇「取得連結」，並在第二個視窗中開啟該連結。在其中一個視窗輸入，看另一個視窗隨之更新。這同樣需要訂閱。

準備好之後，從「檔案」功能表選擇「新增」建立空白文件，需要提供檔案給別人時則選擇「下載」。

## 還有更多

- **Word、OpenDocument、Rich Text、PDF、HTML、EPUB、Markdown、LaTeX、AsciiDoc、reStructuredText、Org、CSV 和純文字**都能以可編輯的文件開啟。
- **命令面板：** 按 Ctrl+Shift+P（Mac 為 Cmd+Shift+P）可搜尋並執行任何命令。
- **頁面縮圖：** 「檢視」›「頁面側邊欄」（Alt+P）會顯示一欄頁面，供您快速跳轉。在 PDF 中，可以拖曳頁面來重新排序，也可以刪除。
- **重新命名：** 按一下功能表列中間的文件名稱，即可輸入新名稱。
- **連結與表格：** 按 Ctrl+K（Mac 為 Cmd+K）為選取的文字加上連結，工具列的「表格」按鈕可插入表格。
- **拼字與文法：** 按 F7。「尋找與取代」在「編輯」功能表中。
- **註解：** 選取文字，然後從「插入」功能表選擇「註解」。其他人可以回覆，問題處理完畢後，您可以將註解標示為已解決。
- **佈景主題、深色模式和工具列**在「檢視」功能表中，「工具」功能表可切換語言。

## 儲存與訂閱

沒有儲存按鈕。您所做的每項變更，稍後都會保存在這個瀏覽器中，也不需要帳號。「檔案」›「開啟」會顯示您所有的文件，需要檔案時，「下載」隨時都能給您一份。在瀏覽器中儲存與下載都是免費的，不需要訂閱。

訂閱可增加同步、共用和內建的 AI 助理：

- **同步**會將您的文件儲存在帳號中，方便在任何裝置上開啟。
- **共用與共同編輯**，可透過連結或與特定人員進行。
- **AI** 已內建，不需要任何設定。

訂閱也是支持 Golem Docs 開發的方式。如果訂閱結束，您的文件仍會保留在這個瀏覽器中，也仍可開啟訂閱者與您共用的文件。費用請見[價格](https://golemdocs.com/home/#pricing)，或選擇「檔案」›「訂閱…」開始使用。

## 關於名稱

在猶太傳統中，魔像（golem）是以黏土塑成、由一個字賦予生命的形體。最著名的傳說中，布拉格的猶大·勒夫拉比用伏爾塔瓦河的泥土塑出一個魔像，並在它的額頭寫上 *emet*，希伯來文的「真理」。擦掉第一個字母，這個字就變成 *met*，意思是「死」，魔像便回歸塵土。

文件也很相似：原本是無形之物，由文字賦予生命。Golem Docs 讓您的文件能變成任何需要的形式，無論是 Word、Markdown、PDF 或網頁，而您所寫的內容在底層始終真實不變。
