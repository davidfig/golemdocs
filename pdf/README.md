# @golemdocs/pdf

A from-scratch, dependency-free PDF reader and writer. Reads real-world files (damaged, encrypted, incrementally updated), extracts text with positions, edits the object graph, and writes new documents with embedded, subset fonts and images.

```ts
import { PdfDocument } from '@golemdocs/pdf';

// Reading
const doc = PdfDocument.load(bytes, { password: 'optional' });
doc.pageCount;
doc.pages[0].extractText();          // { text, items: [{ text, x, y, width, fontSize, fontName, ... }] }
doc.getMetadata('Title');
doc.outline;                         // bookmarks as a tree

// Writing
const out = PdfDocument.create();
const font = out.embedFont(ttfBytes);            // TrueType or OpenType; subset on save
const page = out.addPage([612, 792]);
const g = page.draw({ origin: 'top-left' });     // y down, like layout
g.text('Hello', 72, 72, { font, size: 12 });
g.textRun([{ text: 'W', advance: 11.2 }, { text: 'ord', advance: 19.9 }], 72, 90, { font, size: 12 });
g.rect(72, 100, 200, 40, { fill: [0.9, 0.9, 1], stroke: { color: 0, width: 0.5 } });
g.image(out.embedImage(pngOrJpegBytes), 72, 150, 200, 150);
g.finish();
page.addLink([72, 700, 200, 720], 'https://example.com');
const pdfBytes = await out.save();                // or { incremental: true } after editing a loaded file
```

`textRun` takes the advances layout computed and emits them as TJ adjustments, so glyphs land exactly where layout put them (and extract back as the same text), whatever the font's own widths or kerning say.

## Layers

| Layer | Files | Notes |
|---|---|---|
| Objects | `src/core/objects.ts`, `parser.ts`, `serialize.ts` | The eight object types plus references. Lenient tokenizer (bad stream lengths, stray tokens, malformed numbers read as Adobe does). |
| Cross-reference | `src/core/xref.ts` | Tables, xref streams, hybrid files, `/Prev` chains, junk before the header; rebuilt by scanning when damaged. |
| Document | `src/document.ts`, `page.ts` | Lazy, cached object loading (object streams included); page tree with inheritance; add/remove/move/copy pages; full save (renumbered, unreachable objects dropped, object + xref streams) or incremental save (appended, original bytes untouched). |
| Filters | `src/filters/` | Hand-written inflate (tolerant of truncation), LZW, ASCIIHex, ASCII85, RunLength, PNG/TIFF predictors. Flate encoding uses the platform's `CompressionStream`. Image codecs (DCT, JPX, JBIG2) are left encoded; CCITT fax (`ccitt.ts`, Group 3 and 4) is decoded for images by `render/image.ts`. |
| Encryption | `src/crypt/` | The standard security handler, revisions 2–6 (RC4 40/128, AES-128, AES-256), user and owner passwords, SASLprep. MD5, SHA-2 and AES are hand-written (Web Crypto is async and lacks MD5/RC4). Encrypted files are decrypted on load and saved unencrypted. |
| Fonts | `src/fonts/` | CMaps (embedded and Identity/Unicode predefined), simple-font encodings, the Adobe Glyph List, standard 14 metrics (generated by `scripts/generate-font-data.py`), a TrueType/OpenType parser and subsetter. `program.ts` reads the glyph outlines of the font programs a PDF embeds (Type 1 in `type1.ts`, CFF in `cff.ts`, TrueType), for drawing pages with their own fonts; it is imported as `@golemdocs/pdf/fontProgram`, not from the package index, so only the PDF viewer's chunk carries it. |
| Text | `src/text/` | Content interpretation for text: fonts, text/graphics state, form XObjects, annotation appearances (opt-in); joined into lines and words. Falls back on the embedded font's cmap when a file has no ToUnicode. |
| Writing | `src/write/` | Drawing API, standard and embedded fonts (Type 0 / Identity-H with ToUnicode), JPEG/PNG/raw images (alpha → SMask), links and outlines. |

## Not yet

- Right-to-left text comes out in visual order (no bidi reordering).
- Predefined CJK CMaps other than Identity and the Unicode ones (Adobe-Japan1 etc.) aren't bundled; such text extracts only where the file has a ToUnicode map.
- Writing encrypted files, linearization, tagged PDF/accessibility structure, forms (reading or filling), and variable-font instancing when embedding.
- Rendering. This package reads and writes the file format; drawing pages is a separate problem.

## Tests

```sh
pnpm --filter @golemdocs/pdf test            # unit tests and fixtures (test/fixtures, see its README)
pnpm --filter @golemdocs/pdf fetch-corpus    # once: pdf.js's ~1,000 test PDFs into .cache/pdfjs
pnpm --filter @golemdocs/pdf corpus          # load → text → full and incremental save → reload, for every file
```

On the pdf.js corpus every file loads or is rejected for a reason (not a PDF, needs a password), none crash, and every full save reloads with the same pages and text. Extracted text averages 96% character recall against poppler's `pdftotext`, and most of the gap is files where poppler's output is itself garbage.
